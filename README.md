# AI-Augmented Sales Analytics Dashboard

## 🧾 Overview
An end-to-end retail sales analytics dashboard project integrating AI components such as forecasting and anomaly detection. Built using Python, SQL, and Excel to support business decision-making.

## 🔧 Tools & Technologies
- Python (Pandas, Prophet, Matplotlib, Seaborn)
- SQL (PostgreSQL-style queries)
- Excel (Pivot Tables, Slicers, Charts)
- Jupyter Notebooks

## 📊 Features
- Time series forecasting of monthly sales using Facebook Prophet
- Anomaly detection using Z-score
- Automated business insights from data trends
- Interactive Excel dashboard for product/region performance

## 📁 Project Structure
- `data/` – Input datasets (Superstore)
- `sql/` – SQL scripts for data extraction and transformation
- `notebooks/` – Python notebooks for analysis, forecasting, and insights
- `dashboard/` – Excel dashboard file
- `outputs/` – Charts and reports generated

## ✅ Results Summary
- Forecasted 6-month sales with 91.3% accuracy
- Detected 15+ anomalies (up to 27% variance from average)
- Automated insight generation for 5 key business KPIs
- Dashboard analyzing 5,000+ transactions across 17 categories and 4 regions

## 📌 How to Run
1. Run SQL scripts to prepare data
2. Use notebooks to clean data, forecast, and generate insights
3. Open Excel dashboard and refresh Pivot Tables
